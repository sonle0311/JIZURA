## Alignment engine

Create `alignment/` Python worker and isolated `.venv-sync` setup script. Pin a compatible stable WhisperX dependency. Use small multilingual ASR (base default, CPU int8), align recognized segments with the language's wav2vec2 model, and match supplied lyric tokens against recognized word timestamps using monotonic sequence alignment. Repeated choruses must consume later occurrences in order. Preserve original lyric text, punctuation/diacritics and source line indices; normalization exists only for matching. Optionally refine matched supplied lines using WhisperX forced alignment inside bounded windows. Limit acoustic alignment windows to avoid allocating a whole-song CTC trellis. Missing/weak anchors produce explicit review/unmatched results, not fabricated confidence.

Result confidence is a heuristic match/alignment score, not a calibrated probability. Rows: `{index,text,start:number|null,end:number|null,confidence:0..1,status:'matched'|'review'|'unmatched'}`. Return every supplied line exactly once. Only real, finite, chronological times within the audio duration may be proposed; low-quality/missing evidence stays unmatched or review. `warnings` are safe codes/text, never raw stacks. Declared languages include Vietnamese and English; auto-detection supported by the ASR. Engine checks report availability/dependency state without downloading models. CLI stdout is bounded JSON-line events `{type:'progress',stage,progress?}` and final `{type:'result',result:{language,duration,lines,warnings}}`; errors exit nonzero with safe diagnostics. Heavy library logs go to stderr.

Worker input: `--audio <local WAV path> --metadata <JSON path>`; metadata `{language:'auto'|language-code,lines:[{index,text,locked}]}`. `--check` emits availability metadata only. Browser sends mono 16kHz PCM WAV generated from the current decoded AudioBuffer. Worker validates duration <=600 seconds, max200 lines/30000 lyric chars, file/sample limits and text. Audio duration comes from actual samples, not trusted metadata. Tests use deterministic word fixtures plus an actual short generated spoken-audio smoke if model installation succeeds. Singing/Vietnamese accuracy remains explicitly unverified without representative audio.
